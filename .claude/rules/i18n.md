# Bilingual (Arabic default, English)

- Locales come from `@nosa/contracts` (`LOCALES`, `DEFAULT_LOCALE = "ar"`, `LOCALE_DIR`). Never retype them.
- Every route lives under `app/[locale]/`. Links always include the locale: `/${locale}/shop`.
- UI text: `frontend/src/shared/i18n/dictionaries/{ar,en}.json` — add every key to BOTH files.
  Server Components call `await getDictionary()`; Client Components receive translated strings as props.
- Database text uses `LocalizedText` (`{ ar, en }`) — product names, descriptions, categories,
  banners, CMS. The backend returns both; the frontend `*.data.ts` picks the active locale.
- Money: EGP, formatted with `Intl.NumberFormat(locale)` through a single shared formatter.
- Dates: shared formatter with `Intl.DateTimeFormat(locale)`.
- Layout must work in RTL and LTR — see logical-class rule in `tailwind-design-tokens.md`.
- Arabic copy is written in friendly Egyptian Arabic aimed at mothers and gift buyers.
